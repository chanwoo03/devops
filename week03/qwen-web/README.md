프로세스 치환(Process Replacement): 쉘 내장 명령어인 exec는 새로운 자식 프로세스(Child Process)를 생성(fork)하지 않음. 대신 현재 실행 중인 쉘 프로세스(Bash, Zsh 등)의 메모리 공간을 python3 chat.py 프로세스로 완전히 덮어씌움.

PID(프로세스 ID) 유지: 기존 쉘이 사용하던 PID를 파이썬 프로세스가 그대로 승계함.

쉘 복귀 불가: 프로세스가 대체되었으므로, chat.py 실행이 완료되거나 오류로 종료될 경우 원래의 쉘 환경으로 돌아가지 않고 터미널 세션 자체가 함께 종료됨.


<< (리다이렉션 기호): 지정된 종결 문자열(구분자)이 단독으로 나타나는 라인을 만날 때까지, 그 사이의 모든 텍스트 라인을 하나로 묶어 앞의 명령어에 전달함. 별도의 파일 생성 없이 스크립트 내에서 긴 문자열을 주입할 수 있음.

EOF (구분자 지정): 관례적으로 사용되는 'End Of File'의 약어임. (EOF 대신 END, STOP 등 임의의 문자열 사용 가능)

' ' (싱글 쿼트 적용 - 핵심 포인트): 구분자를 따옴표로 감싼 행위는 쉘(Shell)에 환경 변수 확장(Parameter Expansion) 및 명령어 치환(Command Substitution)을 강제로 차단하라는 지시임. 입력되는 텍스트 내부의 특수 문자($, `, \ 등)를 쉘이 해석하지 않고 원시 문자열(Literal Text) 그대로 전달함.
